# 오늘의 할 일

할 일을 추가하고, 완료 여부를 체크하고, 남은 할 일 개수를 확인할 수 있는 개인용 웹앱입니다.

## 실행하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 여세요.

## 데이터 저장

할 일은 현재 브라우저 프로필의 `localStorage`에 저장됩니다. 다른 브라우저나 기기와 동기화되지 않으며, 브라우저의 사이트 데이터를 지우면 저장된 할 일을 복구할 수 없습니다.

저장 코드는 [`lib/task-storage.ts`](./lib/task-storage.ts)에 모여 있습니다. 화면은 이 모듈의 비동기 함수만 사용하므로, 나중에 데이터베이스를 연결할 때 저장 구현을 교체할 수 있습니다.
