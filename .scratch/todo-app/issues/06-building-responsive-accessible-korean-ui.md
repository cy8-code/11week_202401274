# 06: Building a responsive and accessible Korean UI

**What to build:** A user can comfortably understand and operate the task app in Korean on mobile and desktop, including with a keyboard or assistive technology.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] The interface uses Korean copy and a light-only theme.
- [x] The layout and controls remain usable at mobile and desktop viewport sizes.
- [x] The task input, completion controls, and delete actions have accessible labels.
- [x] All actions can be operated with a keyboard and show a visible focus indicator.
- [x] Status and storage error messages are exposed to assistive technology.
